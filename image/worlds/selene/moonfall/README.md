# Echoes of Moonfall assets

Đặt file ở các thư mục con đã tạo. Không cần file giả khi chưa có media.

- Hướng dẫn: docs/world/selene/ASSET_REQUIREMENTS.md
- Danh sách file: docs/world/selene/world_asset_manifest.json (bản tham khảo)
- Thông số ảnh/video/audio: docs/world/selene/*_REQUIREMENTS.md
- Chỉ các file trong manifest CMS được World phục vụ.
- Nhạc nền dùng chung kho chat thường; reaction dùng image/react/elf.webp.
- Narrator voice cấu hình tại CMS World; voice Selene cấu hình tại CMS nhân vật/chat thường.
- Không đặt credentials, file user private hay văn bản spoiler tại đây.
