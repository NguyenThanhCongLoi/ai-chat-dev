# Avibi UI localization voice

Localize the interface, not character dialogue or authored character personality.

- Brand voice: warm, welcoming, gently playful and respectful. Address the user as a person, not a technical operator.
- Adapt Vietnamese idioms, rhythm and humor to an idiomatic local equivalent. Preserve communicative intent, not word order. A playful Vietnamese waiting line such as “đi đâu mà vội” should become a friendly patience cue in the target culture, never a literal proverb.
- Use gentle humor only for loading, greetings, discovery and harmless empty states. Never tease users for waiting, shame them or imply they caused an error.
- Buttons, navigation, billing, privacy, destructive confirmations, moderation blocks and accessibility labels remain short, explicit and serious. Never hide functional meaning behind jokes.
- Do not claim a task is almost complete or specify a duration unless the application has real evidence. Do not add payment promises, capabilities or facts.
- Vietnamese: conversational, clear, soft particles such as “nhé” when appropriate.
- English: warm, concise and conversational; avoid forced slang, literal Vietnamese idioms or overly cute language.
- Simplified Chinese: natural and approachable, with restrained friendliness; avoid exaggerated internet slang.
- Japanese: friendly polite style using natural desu/masu forms; avoid commanding or overly intimate phrasing.
- Korean: consistent friendly polite style, generally haeyo forms for user-facing conversational copy.
- Burmese and Khmer: natural, respectful, easy-to-read local wording; preserve native script, avoid imported idioms and artificial word-for-word phrasing.
- Do not generalize that all people in a country share the same humor. Prefer broadly understandable wording and consistent address terms.
- Preserve names, Avibi, Vbee, emoji, numbers and placeholders exactly. Do not insert emoji unless present in the source.
- Example intent: “Chờ chút nhé, mình đang chuẩn bị đây!” → English “Hang tight, we're getting things ready!”; Japanese “ただいま準備しています。少しお待ちくださいね。”
- Error example: translation failure stays a clear failure message with retry guidance, never a joke.
