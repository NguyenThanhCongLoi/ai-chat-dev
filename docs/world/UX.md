# Moonfall Academy — experience

## First visit

Open Worlds from the existing AIBox/Roleplay entry. The old quest interface is replaced by an academy landscape. Start one authored world and choose 2–4 existing characters (four preselected when available). Character identity stays intact; world roles and memories are separate. VI/EN demo text, same account and private progress.

## Five-minute loop

1. On the map, follow the glowing Library node.
2. Meet two familiar characters; chat freely if a CMS Roleplay model and moderation are configured.
3. Examine the unsigned letter. Hear both witnesses or confront them: these choices change trust and rivalry.
4. Return to map, enter Moon Garden, remember the absent friend.
5. The garden yields a flower and memory lens; Observatory unlocks.
6. Go there and choose whether to share the memory or protect the identity.
7. Read the chapter ending, close it, visit friends or inspect the timeline.

Hints are available without penalties. Free chat does not require selecting a recipient: normally one present character responds; mentioning two present names allows two. Scene-based group interaction replaces Lastlight's separate-NPC-room concept in this new demo.

## Surfaces

- Home: atmosphere, map, living hook and next action first. Progress sits in a quiet footer.
- Map: five nodes, glow, portraits, locked reason, pointer and touch access.
- Scene: portraits on one side, authored or AI dialogue on the other, choices above composer.
- Memories: timeline filters and linked missions; witness names show who experienced each event.
- Bonds: qualitative relationship stage, trust bar, only unlocked secret text.
- Satchel: story keepsakes and consumable gifts; recipients are people in the current scene.
- Cast: footer + opens existing-character selection without cloning them.
- Ending: dismissible reader; can reopen from completion footer.

## Visual and accessibility

Original academy SVG, layered mountains, moon, warm windows, fireflies, gold accents, quiet transitions. Static avatars remain usable through CSS presentation. No image/video generation or asset download is required. Existing avatars are reused when available; initials otherwise.

Native dialog supplies focus containment/Escape. Explicit focus outlines, disabled busy actions, aria-live transcript, mobile bottom drawers and reduced-motion CSS. No hover-only required controls. Primary verification targets desktop; mobile gets a responsive baseline, not exhaustive device certification.

## Deferred product features

No custom theme editor, custom cover upload, public publishing, marketplace, human multiplayer, real-time geographic agent simulation or continuous offline conversations. No fake notifications pretending that ungenerated conversations occurred. The return-day hook is an authored invitation, not an assertion that real autonomous agents acted while absent.
